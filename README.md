# QuickCash

QuickCash is a full-stack mobile career marketplace application developed as part of a Software Engineering project at Dalhousie University. The platform connects employers with short-term workers, enabling seamless job discovery, communication, and secure payments.

## Features
- User authentication and profile management using Firebase
- Location-based job listings powered by Google Maps API
- Real-time notifications for job alerts
- In-app private messaging for direct communication
- Rating and review system to build trust between users

## Tech Stack
- Java
- XML
- Android Studio
- Firebase
- Google Maps API

## Project Context
This project was built as part of a Software Engineering course at Dalhousie University, focusing on full-stack mobile application development, system design, and real-world integrations.
